# Personal Dashboard

Panel personal: finanzas, calendario, contenido, gimnasio, nutrición y agentes. Next.js + Supabase, desplegado en Vercel y empaquetado como APK con Capacitor.

> Proyecto de uso personal. No contiene datos: todo vive en Supabase protegido con RLS.

## Desarrollo

```bash
cp .env.example .env.local   # rellena las variables
npm install
npm run dev
```

Ver `CLAUDE.md` para comandos y convenciones, `DESIGN.md` para el sistema de diseño y `PROGRESS.md` para el estado.
